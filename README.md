# FermentStation

Local-first household fermentation tracking for Android and desktop.

## Development

```powershell
npm install
npm run dev
```

```powershell
npm test
npm run build
npm run cap:sync
npm run android:build
npm run tauri:build
```

`npm run tauri:dev` launches the desktop shell. Rust, MSVC Build Tools, the
Android Studio JDK, and Android SDK paths are configured as user prerequisites.
