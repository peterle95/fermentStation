## Unique-inspired Sofia Sans Extra Condensed

The specimens in `font/` identify Unique by Rajesh Rajput. The application uses **Unique-inspired Sofia Sans Extra Condensed**, not the exact Unique font, for selected static display headings; Outfit remains the body and functional UI face. Unique's embedding license could not be verified.

`SofiaSansExtraCondensed.ttf` is the unmodified upright variable font (weight 1–1000), Copyright 2019 The Sofia Sans Project Authors (https://github.com/lettersoup/Sofia-Sans), distributed under SIL Open Font License 1.1. Full notice and license: `SofiaSansExtraCondensed-OFL.txt`. Embedding and redistribution are permitted with this notice and license.

Source: [Google Fonts binary](https://raw.githubusercontent.com/google/fonts/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/sofiasansextracondensed/SofiaSansExtraCondensed%5Bwght%5D.ttf) and [license](https://raw.githubusercontent.com/google/fonts/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/sofiasansextracondensed/OFL.txt), pinned to commit `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.
