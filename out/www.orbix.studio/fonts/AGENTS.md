# Coding-agent instructions — Unique Typeface

**This is an implementation kit for an existing typeface, not a font-generation project.**

1. Read `README.md`, `docs/AGENT_HANDOFF.md`, and `docs/LICENSING.md` before integrating any assets.
2. Obtain original unmodified Unique fonts from https://rajputrajesh-448.gumroad.com/l/Unique (user downloads/authorizes, retain EULA). Font binaries are intentionally absent from the supplied kit. Do not invent, redraw, substitute, or claim a replica is Unique.
3. Run `pip install fonttools`, then `python scripts/install_fonts.py <extracted-original-fonts>`.
4. Run `python scripts/audit_fonts.py <extracted-original-fonts> --json charset/actual-font-coverage.json` to establish ground-truth glyph coverage and actual OpenType tags.
5. View `specimen/index.html` and test the entire character map for each installed weight. Do not rely on a screenshot, published glyph counts, or fallback rendering as proof.
6. Integrate `web/public/fonts/unique.css` and font assets only after verifying distribution/web embedding terms. Use `web/src/tokens.css` and `web/components/UniqueHeading.tsx` as adaptable patterns.
7. Keep display text visually bold but body text readable with a system/Inter fallback. Test accents, punctuation, multiline mobile wrapping, and zoom.
8. **Do not modify actual font files**: no outline editing, no subset, no format conversion, and no autogenerated variant without written permission. Installer performs byte-for-byte copies.
9. Do not ship `assets/references/*` in a public app; those images are screenshots of the author's promotional artwork, included only for internal reference.

## Deliverable requirements
- Valid font loading with seven 100–700 weight faces or inspected variable font.
- QA matrix from `charset/groups.json` plus actual `cmap` audit.
- Accessible UI text font and robust fallback.
- License/attribution note in project documentation.
