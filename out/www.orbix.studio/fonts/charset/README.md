# Character coverage QA corpus

The typeface's online display reports **367 characters** and **422 glyphs**, but a published page is not a substitute for reading the actual font's `cmap` tables. This folder has **364 distinct visible character targets** compiled into ten QA groups from the online display. Some characters are repeated between groups, and invisible/control characters are intentionally excluded. The corpus is meant to help detect missing letters and punctuation during app integration, not to assert that every target exists in every downloadable font revision.

- `groups.json` — grouped test strings for a browser/type tester.
- `characters.csv` — individual codepoints, names and groups for indexing.
- `characters.txt` — readable grouped character chart.
- `test_strings.txt` — copy/paste phrase and punctuation testing.
- `actual-font-coverage.json` — generated by `scripts/audit_fonts.py` after original fonts are provided; the font binary is the authority.

The fonts are Latin-oriented display faces. Non-Latin writing systems must use fallback fonts, not guessed replacements.
