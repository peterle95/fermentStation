# Licensing and asset provenance

**Creator:** Rajesh Rajput. The designer's original product download: https://rajputrajesh-448.gumroad.com/l/Unique

The published font metadata states: commercial and personal project use is allowed; font files must **not be modified without written permission** from the author; all other rights remain with the author. The user must review the license inside the original font download as the authoritative source. Webfont/app embedding, hosting, and distribution may require confirmation from the designer, particularly when the font data is delivered to end users. Do not assume a website's phrase “free commercial use” constitutes an open-source or redistribution license.

This package does NOT include font binaries or convert OTF/TTF to WOFF/WOFF2. `install_fonts.py` copies original bytes and generates separate CSS declarations; it never edits the font itself. Renamed copies are byte-for-byte identical. No image in `assets/references` should be used in a public app without a separate license for the original artwork. The document's screenshots are reference excerpts from the user-supplied PDF.

No advice here substitutes for reviewing the original EULA. If the final deployment embeds/distributes font files, get written clarification if terms are unclear. Creator's contact listed in published license metadata: rajputrajesh_448@yahoo.com.
